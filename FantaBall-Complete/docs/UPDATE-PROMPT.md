# Weekly update command
Load confirmed configuration, prior snapshot, current ledger and model version. Verify date/horizon. Refresh authorized evidence, prioritizing injuries, recovery, selection, transfers and suspensions. Resolve conflicts. Recompute fixture availability, eligibility, rating probability and scoring. Rerun affected shared-world forecasts/prices/alternatives. Preserve previous snapshot and show metric/previous/new/change/reason/source. Flag stale or low-confidence information. Retrain coefficients only for evaluated reasons. Do not claim execution or scheduling that did not happen.
